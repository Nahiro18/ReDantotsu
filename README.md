ReDantotsu is a premium fan remake of the beloved Dantotsu application. I've taken the robust foundation of the original app and completely reimagined it, introducing a modern UI, expanding core functionality, and implementing crucial stability fixes to deliver the definitive anime and manga tracking experience. / ReDantotsu es un remake fan premium de la querida aplicación Dantotsu. He tomado la base sólida de la app original y la he reinventado por completo, con una UI moderna, más funciones y correcciones cruciales de estabilidad para ofrecer la experiencia definitiva de seguimiento de anime y manga.

## ✨ What's New in ReDantotsu / Novedades en ReDantotsu <a name="whats-new"></a>

We've extensively upgraded the app far beyond a simple visual reskin. Here is what makes ReDantotsu the best version yet: / Hemos mejorado la app mucho más allá de un simple cambio visual. Esto es lo que hace de ReDantotsu la mejor versión hasta ahora:

### 🌟 Brand New Features / Nuevas funciones
- **Expanded Home Experience** - A redesigned home screen featuring dedicated Anime and Manga sections for better content discovery. / **Inicio ampliado** - Pantalla de inicio rediseñada con secciones dedicadas de Anime y Manga para descubrir mejor el contenido.
- **Source Deduplication** - Intelligent handling of extensions to eliminate duplicate entries and streamline your library. / **Deduplicación de fuentes** - Gestión inteligente de extensiones para eliminar duplicados y ordenar tu biblioteca.
- **Enhanced Integration** - Upgraded and fully stable AniList login utilizing modern dashboard redirect URIs, alongside MyAnimeList rating support. / **Integración mejorada** - Login de AniList estable con URIs de redirección modernas, junto con soporte de puntuación de MyAnimeList.

### 🎨 Premium UI Overhaul (Liquid Glass) / UI Premium (Liquid Glass)
- **Real-time Backdrop Blur** - Beautiful glass surfaces that dynamically blur content behind them for an iOS-inspired aesthetic. / **Desenfoque en tiempo real** - Superficies de cristal que desenfocan el contenido de fondo, con estética inspirada en iOS.
- **Redesigned Navigation** - Modern pill-shaped bottom bars and a stunning sliding glass settings overlay. / **Navegación rediseñada** - Barras inferiores tipo píldora y un panel de ajustes deslizante de cristal.
- **Fluid Animations** - Smooth 60fps spring animations with subtle lens distortion and optimized GPU load. / **Animaciones fluidas** - Animaciones spring a 60fps con sutil distorsión de lente y GPU optimizada.
- **Polished Visuals** - Consistent dark/light theming, flawless profile picture rendering, and improved layout consistency. / **Visuales pulidos** - Temas claro/oscuro consistentes, fotos de perfil perfectas y layouts más coherentes.

### 🔧 Core Fixes & Optimizations / Correcciones clave y optimizaciones
- **Stable Core Systems** - Fixed the in-app update checker and resolved complex fragment lifecycle glitches present in the original app. / **Sistemas estables** - Comprobador de actualizaciones arreglado y fallos del ciclo de vida de fragments resueltos.
- **Optimized Performance** - Better memory management using derived state recomposition, allowing for a faster and smoother browsing experience. / **Rendimiento optimizado** - Mejor gestión de memoria con recomposición de estado derivado para navegar más rápido y fluido.

## 📥 Installation / Instalación <a name="installation"></a>

1. Download the latest APK from the [Releases](https://github.com/Nahiro18/ReDantotsu/releases) page. / Descarga el último APK desde la página de [Releases](https://github.com/Nahiro18/ReDantotsu/releases).
2. Enable "Install from unknown sources" if prompted by your device. / Activa "Instalar apps de fuentes desconocidas" si tu dispositivo lo pide.
3. Install and enjoy! / ¡Instala y disfruta!

## 🛠️ Building from Source / Compilar desde código <a name="building-from-source"></a>

```bash
# Clone the repository / Clona el repositorio
git clone https://github.com/Nahiro18/ReDantotsu.git
cd ReDantotsu

# Build debug APK / Compila APK debug
./gradlew assembleGoogleAlpha

# Or build release APK (requires signing config) / O compila APK release (requiere firma)
./gradlew assembleGoogleRelease
```

## 🎯 Features / Características <a name="features"></a>

- **AniList Sync** - Real-time synchronization with your AniList account. / **Sincronización AniList** - Sincronización en tiempo real con tu cuenta de AniList.
- **MAL Sync** - Optional MyAnimeList integration for ratings. / **Sincronización MAL** - Integración opcional con MyAnimeList para puntuar.
- **Discord Rich Presence** - Show off what you're currently watching or reading to your friends. / **Discord Rich Presence** - Muestra a tus amigos qué estás viendo o leyendo.
- **Extension System** - Modular source system for unlimited content discovery. / **Sistema de extensiones** - Fuentes modulares para contenido ilimitado.
- **Offline Mode** - Download content for offline viewing. / **Modo offline** - Descarga contenido para verlo sin conexión.
- **Auto-Skip** - Automatically skip openings, endings, and recaps. / **Auto-salto** - Salta openings, endings y recaps automáticamente.
- **Timestamp Support** - Community-powered timestamps. / **Timestamps** - Marcadores de tiempo de la comunidad.
